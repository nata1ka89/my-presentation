What are APIs?

Application programming interfaces, or APIs, are sets of rules for software systems to communicate with each other and share data.

What is REST?

REST (REpresentational State Transfer) is a software design pattern for APIs on the web.

Here are the main features of REST APIs:

  • Endpoints are explicit.
  • Uses HTTP methods like GET, POST, PUT, DELETE.
  • REST separates the client and server concerns.
  • REST responses are cacheable.

https://api.github.com/users/{username}

https://api.github.com/repos/{owner}/{repo}

Benefits of REST APIs

  • It’s all in the URL
  • Standards-based
  • Caching
  • Language-agnostic
  • Strong community

Disadvantages of REST APIs

  • Over-fetching or under-fetching data
  • Versioning
  • Limited real-time capability

What is GraphQL?

GraphQL is a JSON-like language that was invented in 2012 by engineers at Facebook, and made open source in 2015. GraphQL is a type of API that works via its own Query Language.
  1. With GraphQL, the request is longer but more explicit.
  2. The important information about the request is in the query, rather than in the URL, like in REST.
  3. The URL stays the same, and the endpoint is different.

Benefits of GraphQL APIs

  • Client-specified data requirements
  • Single endpoint
  • Single request
  • Strong typing
  • Real-time data with subscriptions
  • Evolution

Disadvantages of GraphQL APIs

  • Complexity
  • Caching
  • Learning curve
  • Potential for inefficient queries
  • Support
